# Chewy 宠物用品独立站

北美宠物用品电商平台，类 Chewy.com 独立站。

## 技术栈

- **前端**：Vue.js 3 + Vite + Element Plus
- **后端**：Java 17 + Spring Boot 3.x + MyBatis Plus
- **数据库**：MySQL 8.0 + Redis
- **云服务**：阿里云 ECS + OSS + CDN
- **支付**：Stripe + PayPal

## 项目结构

\`\`\`
chewy-pet-ecommerce/
├── frontend/        # Vue.js 前端
├── backend/         # Spring Boot 后端
├── database/        # 数据库脚本
├── docker/          # Docker 配置
├── docs/            # 项目文档
└── .github/         # CI/CD 配置
\`\`\`

## 快速开始

### 前端
\`\`\`bash
cd frontend && npm install && npm run dev
\`\`\`

### 后端
\`\`\`bash
cd backend && mvn spring-boot:run
\`\`\`
